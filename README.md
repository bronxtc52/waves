# wave-autobot

Скилл для Claude Code: большая задача режется на волны, каждая волна — свежая сессия
в tmux и один PR. Архитектор планирует, кодер пишет, тестер и ревьюер проверяют —
каждая роль на своей модели.

Как пользоваться — [SKILL.md](SKILL.md); протокол волны — [PROTOCOL.md](PROTOCOL.md).

Волна сама не мерджит: после её `DONE` диспетчер проверяет гейт (PR, CI, чистое дерево, пин плана),
ждёт мерджа человеком или, при `automerge: true`, мерджит сам, и только после мерджа запускает
следующую волну. `automerge` по умолчанию выключен; он и автозапуск следующей волны требуют `plan_sha256`.

Безопасность: всё, что из окна волны попадает в события и дашборд, проходит вычистку шаблонами
(`redact`). Она скрывает известные формы ключей, токенов, паролей, userinfo в URL и адресов почты,
но полноту не гарантирует (best-effort). Секреты в окно волны не выводить; полный текст остаётся
в `$WAB_DIR`.
